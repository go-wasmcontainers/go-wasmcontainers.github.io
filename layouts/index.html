wctr commands,
WASI containers.

A container here is a WebAssembly module. The wctrd daemon listens on /var/run/wctr.sock and is compatible with the Docker Engine API; wctr is the command a lab teaches and the learner types; the image is an OCI image with os=wasip1 and arch=wasm, run by wazero instead of a Linux kernel. Engine v0.29.1 is released (with networking, published ports, restart policies, health checks, exec, build and compose), and the playground is live: a dashboard and wctr in a browser tab, with no server, with networking and a Join class to a teacher's relay, working offline and keeping its containers across reloads. No shell or stdin in the playground yet.{{ if not (partial "mantra-on.html" .) }} Pure Go, CGO_ENABLED=0. BSD-3-Clause.{{ end }}

Why go-wasmcontainers

A lab should be a web page, not a virtual machine.

Teaching containers usually means provisioning a Linux machine per learner. WASI modules need no kernel, so the same engine that runs natively runs in a browser tab, which is what the playground does.

🔌

Compatible with the Docker Engine API

wctrd answers that API (v1.47 is the version its reference is read from) on /var/run/wctr.sock, and WCTR_HOST points wctr elsewhere. Learners type wctr commands, whose shape is the one they know from containers at work.

🧊

WASI images

An image is an OCI image whose platform is os=wasip1, arch=wasm; the layer is a module. Images are meant to be apt-like, built from pkgx wasip1 bottles — a target go-pkgx is gaining now.

⚙️

wazero executor

Containers run in wazero, a pure-Go WebAssembly runtime: no cgo, no kernel namespaces, one static binary.

🌐

Live: the browser

The playground is a dashboard and a terminal running wctr against WASI containers, entirely in a page, with the browser executor. Containers reach each other by name, a class can be joined, and images and containers survive a reload; it works offline. Cold start is slower than wasmtime (first run of hello: 81 ms in Chromium, 291 ms in Firefox, against 23 ms for wasmtime in one CI run).
